# Claim

Claim is an AI-verified commitment challenge platform where builders put money behind specific shipping claims, supporters pledge for access/perks, and outcomes are proven with evidence.

## Starting wedge

**Claim Ship**: AI builders make public, template-based shipping claims, stake money, and prove completion with repo activity, a live deploy, a demo, and a locked checklist.

Claim should start as commitment infrastructure, not a betting market:

- No yes/no positions.
- No odds.
- No trading.
- No variable betting-style payouts.
- Initial failure route should favor charity donation plus supporter refund/donation options.
